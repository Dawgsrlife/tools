# Batch Converting .HEIF Images to .JPG for Free

## iPhone user and tired of manually converting .HEIF images with shitty online converters? Grab IrfanView and use this script!

1) Download + Run Installer
   
   > It's clean on virustotal.com

2) Prepare your conversion environment using the same directory name as I've done (or edit the batch file accordingly)

3) Put all `.HEIF` files to convert into the `convert` folder and run `convert.bat`; enjoy!

# Batch Downscaling .JPG Images

## Need to post on LinkedIn but your images are too high in resolution? IrfanView supports downscaling too!

Here's a script that takes all `.jpg` images in the `%USERPROFILE%\Documents\Resources\manual\downscale` directory and spits out downscaled versions of them in the `%USERPROFILE%\Documents\Resources\manual\downscale\out` directory.

1. Grab IrfanView (as attached)
2. Prepare your conversion environment as depicted
3. Put all `.jpg` files to downscale in the `downscale` folder and run `downscale_jpgs.bat`; enjoy!
